ホームの大会カード、プログラム進行状況、種目一覧、目標一覧を白いカード・16px角丸・細い区切りで統一。時刻・種目・学年と苗字は共通の ProgramEventSummary で描画し、組・番は展開した結果欄だけに表示する。目標の表・検索・ブロック/種目絞り込み・本人編集は維持し、縞模様や色付き背景を整理。大会切替も既存のセグメント型に揃えた。

お知らせ作成権限者の「…」にアーカイブ/解除を追加。notices.archived_at に保存し、ホーム取得だけで除外する。本文、一覧、リアクション、通知は保持。重要・期限付きもアーカイブを優先する。更新は既存のauthenticated向けcan_create_notice RLSで制限。解除後は従来の既読・締切・表示件数条件に従う。
