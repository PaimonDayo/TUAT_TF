# 2026-09-22 自動更新の負荷軽減

## 大会データの部分更新

ホームとプログラムの自動更新は、ページ全体の再描画から大会プログラムだけの取得に変更した。時刻による「競技中」「次の競技」の切替は端末内で毎分計算し、データは表示中の開催日に5分ごと取得する。結果一覧・人数・最終取得時刻も更新する。

SSRとブラウザの取得は同じ列・並び順の関数へ集約し、本人のクライアントと既存RLSを利用する。非表示中・開催期間外・取得元なしでは取得しない。通信は25秒で中断し、失敗時は表示を保持して次の取得間隔まで待つ。画面復帰で連打せず、同時に複数の取得を走らせない。手動更新の新しいSSRデータを優先し、古い通信の遅い応答で上書きしない。

## メニュー表の同時取得を集約

Googleの同じ月間メニュー表を同時に取得する要求は、処理中のPromiseを共有する。同じサーバープロセスで10件同時に要求されても、タブ一覧1回と対象月CSV1回にまとめられる。既存60秒キャッシュの鮮度は維持。シート・タブ・月を区別し、失敗したPromiseは解放して次の要求で再試行する。失敗月は取得済み扱いにしない。異なるサーバーインスタンス間の共有ではない。
