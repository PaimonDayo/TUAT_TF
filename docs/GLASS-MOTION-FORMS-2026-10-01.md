# ガラスタブの揺れ・スライド操作・練習記録入力の修正

## 原因と変更

- 下部タブは押下中だけ5項目すべてのアイコンと文字をSVGへ描き直していた。実React画面のChromeで、元の文字とSVG文字に縦1.75pxの差を確認。アイコンにも別座標と拡大があり、全体が揺れて見えた。別描画を撤去し、元のDOMを常時表示する。ガラスの選択面の移動・変形・背景屈折は維持する。
- 共通の「全体・短距離」等のセグメントに横スライドを追加。指を離すまでフィルタ値は変えず、離した項目で既存onClickを1回呼ぶ。下部タブと同じばね計算を共有し、文字は固定する。ページ内では控えめな選択面の浮き・伸びに調整。縦移動はページスクロール、外側リリースとpointercancelは取消。通常のタップ・Space・Enterも維持する。
- 実タッチ相当のChrome試験で、子ボタンからグループへのpointer capture移動に伴うlostpointercaptureが伝播してスライドを取り消すことを確認。windowで追跡を続け、実際のpointercancelだけで取り消す。
- 練習記録の項目を白いセクションと明確なラベルへ整理。入力欄は48px以上、強度別距離は狭い幅で折返し、長い見出しも折り返す。距離項目がない設定では空の「強度別距離」見出しを出さない。
- ラベルと入力をidで関連付け、見出しタップで入力へ移れる。新UIの練習記録は長文に合わせて入力欄を伸ばす。共通Textareaの自動高さは枠幅を含め、横幅変更にも追従し、新旧切替時は高さ指定を解除する。保存エラーはalertとして通知する。
- 共通の新UI入力欄にも44pxの最小高さを適用し、以前の小さい高さ指定が残る箇所を補正した。

セグメントの新操作と入力画面の装飾は管理者のアカウント別・端末別opt-in内。下部タブのアイコン安定化は全員共通のタブへ適用。保存payload、DB、GAS、PC jobs、認証、vendorのシェーダー・captureは変更していない。

## 検証

- 90ファイル・551テスト、変更したTS/TSX/JSのESLint、tsc、Next.js 16.3.6の隔離本番相当build・TypeScript・69ルート生成が成功。初回のローカル依存が16.2.9だったため、16.3.6の既存隔離依存へ付け替えて最終確認。稼働中継が使うmainのnode_modulesは触らない。
- Chrome / WebKit、320 / 390 / 1440px、新旧UIの12条件。下部全アイコンと文字は押下前・押下中・取消後で同一座標・同一寸法・不透明を確認。全体SVG描画なし。下部タブの往復後のリンク呼出しは1回。
- セグメントの複数回往復、離指時の1回確定、縦移動・取消、Space、動きを減らす設定、新旧切替中の解除、未選択状態を確認。最終選択面とボタンの座標差は0.06px以内、97.5%幅・125%拡大でも0.08px以内。
- Chrome CDPのブラウザタッチ入力でセグメント横スライド・縦スクロール成功。下部タブもWebGL有効とvendor読込失敗のCSS代替の両方でタッチ往復・取消を確認。
- 練習記録は中長距離/その他、設定式/従来式、標準/文字拡大、新旧切替を確認。全入力のラベル、距離/本数、横はみ出し、保存失敗後の入力保持、未保存から編集継続、長文自動伸長、320px・高さ420pxへの変更と固定保存ボタンの可視性を確認。合成保存成功時の本文・日付payloadも一致。
- 下部背景は既存の実React部員一覧で先頭・途中・最下部・先頭復帰を再確認。新旧UIとChrome/WebKitで座標差0px、capture高さ384px・倍率1.5倍以内を維持。通常版末尾0.5px境界の既存CSS代替条件はそのまま。

ローカル検証資産: `.contingency/glass-motion-ui`、`build-glass-motion-ui.mjs`、`verify-glass-motion.cjs`、`verify-glass-motion-extra.cjs`、`glass-motion-results.json`、`glass-motion-bottom`、`verify-new-ui-bottom.cjs`、`glass-motion-build-verified`。試験保存は合成クライアントだけで、本番の部員データへは書き込まない。
