# 2026-09-28 監査指摘の修正（本番反映待ち）

本日のUI/UX・効率性・セキュリティ報告書に基づき、現行アプリを隔離worktreeで修正。元のmasterの依存関係、既存の未コミット資料、稼働中の定期処理は保持している。

## 実装した修正

### UI/UX（8項目）

- 投票の取消・切替・追加は成功した操作だけ表示へ反映し、失敗を通知。取消成功後に新しい投票だけ失敗した場合も未投票状態を表示する。
- プロフィール・自由目標・会場・記録フォーム設定は共通の未保存確認を使用。変更なしは即閉じる、変更ありは保存／破棄／編集継続、保存中は閉じない。保存例外後も入力を保持。アバターは従来どおり即時保存であり、未保存の破棄対象に含めない。
- 予定・ノートの更新失敗時は表示済みの内容を残し、失敗表示と再試行を用意。中長距離メニューは未取得と前回データありを区別。
- 投票の選択肢入力に共通Inputを使用（モバイル16px）。長文選択肢を折り返し表示し、投票者確認のボタンも追加。
- 記録フォームの項目追加は親フォーム内に展開し、入力用シートを撤去。
- 大会目標と既存FABは配置部品を共有し、画面幅・safe-areaに追従。
- 自由目標・会場の入力欄とラベルを関連付け。

### 効率性（4項目）

- タイムラインは表示ページ末尾の日時・IDを両種類の境界に使用し、途中ページに無い種類を先頭から再取得しない。
- 記録30件＋つぶやき30件の候補から表示する30件を先に選び、その行だけに項目定義・投票・メンション・いいね・コメント・引用を付ける。
- 自由入力の大会結果を開催日でDB側から絞り、直接紐付いた結果とともにID順で全ページ取得。取得失敗を空結果として扱わない。
- お気に入りはSSR値をReact Queryへ引き継ぎ、表示直後の重複取得を撤去。変更イベント、サーバー更新、鮮度切れ後の再訪・復帰で更新する。

base_types系問い合わせの停止は行っていない。呼出元・必要性が未特定という監査結果のため、停止対象と断定できない。実際の待ち時間・課金削減率は未測定。

### セキュリティ（3項目）

- Next.js / eslint-config-nextを16.3.6、直接利用するsharpを0.35.4へ更新。互換範囲内の間接依存・開発依存も修正し、最終ロックファイルのnpm auditは本番依存・全依存とも0件。
- Pushは配信関数とDB制約で対応するHTTPS配信先に限定する。登録RPCと直接書込みにも同じDB制約が適用される。既存購読はPC15件・クラウド11件で、すべてApple/Googleの対応先だった。削除・再登録は行っていない。
- シート返信はユーザー接続で本人の保存済みコメントと対象記録を照合し、本文はDBから取得。同期情報の更新にも本人・対象・本文条件を付け、送信中の変更を検知する。GASは排他とコメントIDの印で再送を抑制し、中断した予約セルを回復する。返信は文字列として保存。末尾への列追加の添字も修正。
