# ガラスUIを一般部員へ開放

2026-10-03 / Codex。オーナー依頼：管理者限定のガラスUIを一般部員もオンにできるようにし、本番環境まで反映する。

最新origin/master `9abba37` から独立worktreeで開始。ガラスUIの設定と表示にある管理者限定条件を撤去し、「表示」設定で全員が選べるようにする。初期off、端末・アカウント別の既存保存キーを維持。一般部員プレビューも通常の部員と同様に設定へ従う。データの閲覧・編集権限やDBは変更しない。

過去の「管理者のみ」「一般部員プレビューは通常版固定」は今回の依頼で変更する。UI統一とAGENTSの現行ルールを更新し、検証・公開結果を追記する。

## 変更・検証

- 設定の「表示」の先頭へ「ガラスUIを使う」を配置し、管理者限定の設定区分を撤去。認証後の描画側も全員の保存設定に従う。一般部員プレビューでも管理権限は増やさず、表示だけ切り替える。
- 既存の `track-app:new-ui:v1:<userId>` を維持し、管理者の保存済み設定を引き継ぐ。個別ロールがない部員も利用できる。初期off・保存不可時のエラー・タブ間通知を維持。
- 管理者限定判定関数と、その撤去された制限だけを検証する3件のテストを除去。アカウント分離・保存失敗・イベント通知などの既存テストは維持。
- Node 24.19の環境確認、TypeScript、対象eslint、Vitest 94ファイル672件、本番用Next.jsビルド成功。
- 実コンポーネントの合成画面で、一般部員の初期off→on→off、再読込で保持、別アカウントoffと元アカウントの復元、ガラスメニューの開閉、プレビュー相当・個別ロールなし・管理者の設定をブラウザ確認。管理操作の権限判定は変更なし。
- DB・migration・本番PCの依存・Vercel設定は変更なし。iOS PWA・Android実機は未確認。本番公開結果は反映後に追記する。
