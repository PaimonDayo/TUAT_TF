# 中長距離メニューの公開CSV反映（2026-10-03）

## 作業開始

- 担当: Codex
- 範囲: `n月メニュー` タブの公開CSVから、既存の中長距離練習予定へ場所・時間・メニュー・ペースを反映する。10月から翌3月のタブを対象にする。
- 元データ: 公開スプレッドシート「練習記録2026.10/1～」の月別メニュー。必要な月のCSVのみ取得し、タブ一覧と各月の短期キャッシュを使用する。
- 10月の表には練習、off、関東女子駅伝、OB戦、理工系が混在する。新規日付の予定登録についてはユーザーに種別の扱いを確認中。既存の練習予定の表示更新は独立して進める。

## 実装と検証

- 既存の中長距離練習予定について、A:Hの月別CSVから場所・時間・メニュー・ペース・補足を表示へ反映する。表示中は60秒ごと、フォーカス復帰時にも再取得する。
- 月タブ一覧は1時間、必要な月のCSVは60秒で再検証する。URLを固定してNextの共有fetchキャッシュを利用し、同時アクセスはプロセス内で1回の取得へまとめる。
- 時間・場所の空欄は既存の予定値を維持する。全ブロック共通予定の時間・場所は、中長距離のシート値で変更しない。読み込み失敗時はその月のDBメニューを維持する。
- 年なし日付はこのブックの2026年10月から2027年3月にだけ対応させる。以降の月タブも、その期間内なら同じ処理で反映する。
- `npm run check:environment`、`npx tsc --noEmit --incremental false`、対象eslint、`npx vitest run`、`npm run build`を通過。Vitestは95ファイル・684件。実機の表示とGoogle側での更新反映は未確認。
- 予定が存在しない日付の新規登録は未実装。10月の表にはoffと大会が混在するため、登録対象について回答待ち。DBの一括更新・migrationは行っていない。
