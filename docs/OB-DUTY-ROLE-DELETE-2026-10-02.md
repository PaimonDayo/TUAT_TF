# OB戦の補助員役職削除・現在の担当表示

2026-10-02 / Codex。依頼：余分に作った役職を削除し、担当者一覧で現在の種目の補助担当が分かるようにする。

最新origin/master `608c6d3` から独立worktreeで作業開始。役職の共通「…」メニューへ削除を追加し、確認後に削除する。担当者のいる役職は先に割り当てを解除し、既存の担当を削除へ巻き込まない。会員ID・参加回答ID両方の担当をDBで確認し、同時割り当て・編集競合・0件削除を成功にしない。

候補一覧は編集中の役職も含め、保存済みの現在種目の補助担当を役職名で表示。保存前のチェック操作と既存の担当表示を区別し、前後予定・同時刻別種目の除外・未登録者対応を維持する。両DBの退避、ROLLBACK検証後にmigrationを適用し、コード検証と本番確認を行う。

## 実装・検証

- 共通ActionMenuの「役職を削除する」で種目・役職名を確認して削除。担当者がいる役職では削除を表示せず、DBでも会員・未登録参加者の担当を検出して拒否。失敗時は確認画面を維持して再試行できる。
- 候補一覧に「■ この種目の補助担当：役職名」を表示。編集中の役職、別役職、旧形式の自由記入、候補条件から外れた割当済み担当を含む。未保存の選択を保存済みの担当と誤表示しない。
- migration `20261002040000` は新規表なし。既存の共通advisory lock、revision照合、削除IDの返却検証を使用。既存の `zz_log_failover_change` が削除を記録し、PCへの再送にも割当保護を適用する。ミラーの正規反映は既存の判定で除外する。
