# 大会結果の種目別入力フォーム（2026-10-01）

## 変更内容

種目を選ぶと、その種目の記録に必要な欄を表示する。「その他」は種目名と記録の入力形式を選び、必要な場合だけ「風速を入力する」を有効にする。新旧UIの両方に適用する。

| 種目 | 入力欄 | 風速 |
| --- | --- | --- |
| 100m・200m・100mH・110mH | 秒 | 表示 |
| 400m・400mH・4×100mR | 秒 | 非表示 |
| 800m・1500m・3000m・5000m・10000m | 分・秒 | 非表示 |
| 3000mSC・5000mW・10000mW・4×400mR | 分・秒 | 非表示 |
| ハーフ・マラソン・駅伝 | 時・分・秒 | 非表示 |
| 走幅跳・三段跳 | 距離（m） | 表示 |
| 走高跳・棒高跳 | 高さ（m） | 非表示 |
| 砲丸投・円盤投・ハンマー投・やり投 | 距離（m） | 非表示 |
| 七種競技・十種競技 | 得点 | 非表示 |
| その他 | 秒／分・秒／時・分・秒／メートル／得点から選択 | 得点以外で任意に追加 |

風速対象は日本陸連2026年競技規則の[トラック競技 TR17.12](https://www.jaaf.or.jp/pdf/about/rule/2026/15.pdf)・[フィールド競技 TR29.12](https://www.jaaf.or.jp/pdf/about/rule/2026/16.pdf)に対応。秒・分・時の区分は入力を助けるための設定で、競技規則に合わせた計時精度の変更ではない。リレーなど従来と入力の区切りが変わる種目も、保存する値は同じ。

既知の29種目と限定した表記揺れには共通の定義を使い、それ以外の登録種目は既存の種目カタログを参照する。＋ボタンからの種目取得にも `time_format` を含め、他の入口とそろえた。種目未選択時は数値の記録欄を出さない。

## 編集・保存時の扱い

- 秒・分・時の切替時は記録全体を換算する。例：61.85秒は1分1.85秒、28時間は100800秒または1680分になる。生成した総分・総秒も編集でき、保存先の整数上限を超える入力は拒否する。
- メートル・得点へ切り替えて戻る場合も、入力中のタイムと単位を保持する。未完の小数を別の時間形式へ切り替えるときは修正を促す。
- 既存記録は構造化された秒・距離・得点の列を優先して開く。旧自由入力は単位付き文字列を読み、曖昧な小数を距離と決めつけない。削除済みの種目、遅れて届くカタログ更新でも入力済みの単位と記録を保つ。
- 既存の風速は0・負数を含めて保持する。新規の風速対象外種目には欄を出さない。非表示にした風速とDNS等の記録なし状態はnullで保存する。「その他」の風速を外して付け直すと下書き値が戻る。
- 「その他」で選んだ入力形式はフォーム内で保持し、保存後は既存の数値列と記録文字列から復元する。専用の設定列は追加しないため、0時間の時・分・秒など同じ値を表す入力形式までは永続化しない。
- 風速は従来の＋追い風／−向かい風のボタンと数値欄を使う。小数第1位・20.0m/s以内を確認し、空欄と0を区別する。

保存単位は従来の1/100秒・cm・点。DBの種目定義・記録、表示側の書式、PB/UB、認証・権限、GAS・PC定期処理、下部ガラスタブ・vendorは変更していない。実ユーザーの記録への試験書込みは行っていない。
